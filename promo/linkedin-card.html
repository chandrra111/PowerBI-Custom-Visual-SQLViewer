◆ Power BI Custom Visual

Power BI is great at charts.
It is terrible at showing SQL.

Drop a stored-procedure definition into a Card visual and 200 lines collapse into one grey wall of text. So I built a visual that renders it properly.

Before — native Card visualunreadable
CREATE PROCEDURE dbo.usp_GetCustomerRevenue @StartDate DATE, @EndDate DATE AS BEGIN SET NOCOUNT ON; SELECT c.CustomerID, c.CustomerName, SUM(o.TotalAmount) AS Revenue, COUNT(*) AS OrderCount FROM dbo.Orders AS o INNER JOIN dbo.Customers AS c ON c.CustomerID = o.CustomerID WHERE o.OrderDate BETWEEN @StartDate AND @EndDate AND o.Status = 'Completed' GROUP BY c.CustomerID, c.CustomerName HAVING SUM(o.TotalAmount) > 1000 ORDER BY Revenue DESC; END
